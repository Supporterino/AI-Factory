3 Permissions: permissions: [{action, resource, effect: allow|ask|deny}]; LAST matching wins; no match = ask. Stack: base defaults → built-in agent rules → global → agent → session. Any deny on any resource denies call. Defaults allow all except .env reads (ask); external_directory ALLOWED by default. Wildcards: * matches anything INCLUDING '/'; ? one char; "git status *" matches bare "git status". Actions: shell (was bash), edit (edit+write+patch), subagent (was task), read, glob, grep, webfetch, websearch, skill, question, external_directory, <mcp>_<tool>, execute. edit/read resources = paths relative to session dir → path-scoped edit rules work. Shell commands split into subcommands, each checked. Headless ask: `opencode run` auto-rejects w/ message to model (model continues); --auto (aliases --yolo, --dangerously-skip-permissions) approves once; deny always enforced [S cli/src/run/noninteractive.ts].

SDK: @opencode/client (V2; @opencode-ai/sdk is V1); @opencode/sdk embeds server in-process. session.create({location:{directory}, agent, model, permissions, parentID}); session.prompt({sessionID, text, files, delivery}) — NO per-prompt agent, use session.switchAgent; event.subscribe() (GET /api/event); session.interrupt; experimental session.wait; permission reply POST session/{id}/permission/{req}/reply {decision: once|always|reject}.

6 Parallel: one server, many concurrent sessions, each own location.directory [X second dir]. All servers share SQLite ~/.local/share/opencode/opencode.db (WAL, busy_timeout 5000); OPENCODE_DB or XDG vars relocate. RISK (code-read only): a --standalone server on start resumes every session marked in-progress that it doesn't run itself (keyed by session id) → a second standalone could hijack another live process's session. Use one shared server or separate DB per process.

7 Subagents: tool `subagent` {agent, description, prompt, model?, sessionID?, background?} → child session; depth experimental.subagent_depth default 1; same-step calls may run concurrently; background:true returns immediately.
